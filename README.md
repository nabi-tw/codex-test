# ことのは — N4 文法ノート

アップロードされた「N4 - TRY!.csv」の93項目を、繁体字の意味・接続・313の例文とともに学べるアプリです。

- 文型の読みを使った五十音順の一覧・行別の絞り込み
- 日本語・読み・繁体字の意味・例文を横断する検索
- カードのクリック、またはキーボード操作による例文の開閉
- 文法の保存と保存一覧（このブラウザの localStorage に保存）
- スマートフォン・タブレット・パソコンに対応

## 開発

Node.js 20.19 以上、または 22.12 以上を使用してください。

```sh
cd /workspace/codex-test
npm ci --cache /tmp/kotonoha-npm-cache
npm run dev -- --port 5173
```

## ビルド

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` が静的サイトとして配信できる成果物です。データはアプリに含まれ、API・データベース・認証設定は不要です。Google Fonts が使えない環境では端末のフォントを使います。

## サーバーなしで使う

`npm run build` で、ブラウザで直接開ける単体ファイル `dist/kotonoha.html` も生成します。このHTMLをダウンロードしてChrome、Edge、Safariなどで開くと、インターネット接続やNode.jsなしで文法検索・例文表示が使えます。HTML版では外部フォントも読み込みません。お気に入りの永続化はブラウザのローカルファイルに対する保存設定によります。

## 検証

```sh
npm test
```

このクラウド環境の `/usr/bin/chromium` を使用します。別の環境でChromiumがない場合は、先に `npx playwright install chromium` を実行してください。テストでは93項目・313例文の保持、読み順、キーボードでの開閉、検索と絞り込み、保存の永続化、360〜1280pxの表示を確認します。

## データ

`src/grammar.json` にCSVの文法・繁体字の説明・接続・補足説明・例文を収録しました。同じ文型の異なる用法は別項目として保持し、識別用の用法ラベルを付けています。「可能形」の例文欄は空だったため、同じCSVの詳細説明欄にある3例を使いました。中国語は元データの繁体字を使用しています。語頭の「〜」などの記号は読み順に含めず、漢字の文型名には読みを設定しています。

保存は端末・ブラウザごとに独立しています。複数端末での同期機能はありません。
